Import filter assignments from a spreadsheet

Bulk-add catalog items, alternates, and equipment links
Cancel

Reads the Active List sheet of an .xlsx file with columns Unit, Main P/N, Type, OEM Number, OEM Brand, Fram, Donaldson, Fleetguard, Baldwin, NAPA, Other, and Notes — any other columns are ignored. Column order doesn't matter.

Each row becomes a shared catalog item (Type as the category, Main P/N as the part number), linked to Unit. The same part number reused across multiple units becomes one shared item instead of a duplicate. Fram/Donaldson/Fleetguard/Baldwin/NAPA become alternate part numbers (skipped where they just repeat the primary number); a comma-separated Other cell becomes one alternate per value. OEM Number/OEM Brand are saved as a unit-specific info field rather than a shared alternate, since the same filter often has a different OEM cross-reference on different equipment. Rows for a unit that doesn't exist yet are skipped.
