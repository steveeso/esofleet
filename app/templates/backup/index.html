How to restore a backup
  1. Stop the server (see the README).
  2. Rename instance/fleet.sqlite to something like fleet.sqlite.old — don't delete it yet.
  3. Copy the backup file into instance/ and rename it fleet.sqlite.
  4. Start the server again and check things look right.

Restoring isn't a button here on purpose: overwriting the live database from a browser is too easy to do by accident.
